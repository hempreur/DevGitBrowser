Politique de confidentialité

Assistant communautaire officiel du navigateur DevGitBrowser sur Discord.

Dernière mise à jour : 12 novembre 2026

Conditions d’utilisationPolitique de confidentialitéSite DevGitBrowser

1. Responsable et portée

DevGitBrowser Bot est exploité pour la communauté DevGitBrowser par l’équipe du projet CodexHempreur INC. Cette politique porte sur les interactions avec le bot dans le serveur Discord DevGitBrowser ; les traitements opérés directement par Discord relèvent aussi de sa politique de confidentialité.

2. Données utilisées

  • Identifiants Discord : identifiant de serveur, de membre et de salon nécessaires pour exécuter les commandes, attribuer un rôle et ouvrir un ticket.
  • Tickets : identifiant de l’auteur, catégorie et état du ticket enregistrés dans le sujet du salon Discord ; messages et pièces jointes que vous choisissez de publier dans ce salon.
  • Suggestions : texte envoyé et pseudonyme affiché dans le message de suggestion, avec les réactions de vote Discord.
  • Rôle d’alerte : appartenance au rôle Discord de notifications, uniquement à votre demande.
  • Bienvenue : événement d’arrivée d’un membre si l’option d’accueil est activée.
  • Journaux techniques : erreurs de fonctionnement et événements limités de tickets dans les journaux du conteneur et, s’il existe, dans un salon de journalisation du serveur.

3. Finalités

Ces données servent uniquement à gérer les demandes d’assistance, limiter les tickets en double, sécuriser l’accès aux salons privés, recueillir les idées, attribuer les rôles choisis, informer la communauté et diagnostiquer les erreurs techniques.

4. Fonctionnement et tiers

Le bot utilise les API officielles de Discord et s’exécute sur un serveur VPS administré par le projet. Il ne demande pas l’autorisation Message Content pour lire les conversations générales, n’accède pas à vos messages privés et ne met pas en place d’analyse publicitaire ou de revente de données. Les messages envoyés dans les tickets restent hébergés sur l’infrastructure Discord. Le code du bot est disponible dans le dépôt GitHub du projet.

5. Visibilité et conservation

Les tickets ouverts sont visibles par leur auteur et l’équipe disposant des permissions nécessaires. Lors de l’archivage, les messages peuvent rester conservés dans le serveur Discord pour un suivi par l’équipe ; ils ne sont pas automatiquement effacés. Les suggestions publiées dans un salon communautaire sont visibles aux membres ayant accès à ce salon. Les journaux techniques restent sur l’infrastructure exploitée par le projet jusqu’à leur rotation ou suppression par l’administrateur.

Il n’existe actuellement pas de délai automatique unique de suppression des tickets : une demande d’effacement peut être adressée à l’équipe.

6. Vos demandes

Vous pouvez désactiver le rôle d’alertes via /mes-roles. Pour demander l’accès, la rectification ou la suppression des données liées à un ticket ou à une suggestion, contactez l’équipe via un ticket Discord DevGitBrowser. Indiquez le salon ou la suggestion concernés sans joindre de données sensibles. Le traitement d’une demande peut nécessiter de vérifier que vous êtes l’auteur concerné et dépend des limites techniques de Discord.

7. Sécurité et précautions

Le bot limite les accès aux tickets par permissions Discord et neutralise les mentions de masse dans ses messages automatisés. Toutefois, aucune transmission en ligne n’est totalement exempte de risques. Ne partagez jamais de mots de passe, de jetons d’accès ou de documents sensibles dans le bot ou ses tickets.

8. Modifications et contact

Cette politique peut évoluer avec les fonctions du bot ; sa date de mise à jour figure en haut de page. Pour toute question relative à vos données, contactez l’équipe du projet sur le Discord DevGitBrowser.
