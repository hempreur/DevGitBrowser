DGBx, le mode caché.

DevGitBrowser intègre un mode secret réservé aux personnes majeures : une interface dédiée, sombre et élégante, qui regroupe des plateformes adultes légales et connues, classées par catégorie, avec recherche et favoris.

  • Invisible par défaut : aucun bouton ni menu, il ne s'ouvre qu'avec une commande secrète
  • Confirmation de majorité obligatoire à la première ouverture
  • Code d'accès facultatif (4 à 8 chiffres), avec blocage après plusieurs erreurs
  • Navigation privée : rien dans l'historique ni dans la session restaurée, et tout se ferme en un clic sur « Quitter DGBx »
  • Les plateformes sont seulement listées : DevGitBrowser n'héberge aucun contenu

La commande d'accès est réservée aux personnes majeures.

Tape %SxOnSite% dans la barre d'adresse de DevGitBrowser, puis appuie sur Entrée.

Contenus réservés aux adultes. Si des mineurs utilisent ton ordinateur, active un code d'accès DGBx et le contrôle parental de Windows (Microsoft Family Safety).
