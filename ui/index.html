DÉVELOPPEMENT • INTÉGRATION

GitHub privé

Seules les extensions du dépôt privé lié à ton compte peuvent être chargées.

Non connecté à GitHub

1. Connecter ton compte

Crée un fine-grained personal access token sur GitHub, avec la permission Contents: Read uniquement pour ton dépôt privé. Le jeton est chiffré localement avec les services Windows, jamais intégré à l’installeur.

2. Dépôt privé autorisé

Le dépôt doit appartenir au compte connecté. Les extensions doivent se trouver dans extensions/nom-extension/manifest.json.

Ajout automatiqueAprès chaque push sur GitHub, l’application vérifie le dépôt toutes les 90 secondes et ajoute les extensions compatibles. Aucun dossier local externe n’est accepté.

RÉSEAU • CONFIGURATION

Paramètres du navigateur

Performances, confort, téléchargements, confidentialité et réseau. Pas de VPN intégré.

Performances et rendu

Le mode équilibré conserve une visioconférence fluide. Le mode éco réduit la fréquence des contrôles GitHub en arrière-plan et conserve le ralentissement natif des onglets inactifs. Le matériel vidéo utilise les ressources nécessaires au direct.

Accélération graphique

Conseillée pour les appels vidéo. Désactiver uniquement en cas de problème de pilote graphique. Nécessite un redémarrage, peut augmenter la charge CPU.

Outils de page

Rechercher dans le texte de la page, imprimer ou enregistrer en PDF avec la boîte de dialogue Windows.

Analyse réseau & compatibilité ancienne

Ouvre une fenêtre réseau Windows indépendante qui lit en direct les requêtes HTTP, les réponses, les statuts et les en-têtes de l’onglet actif. L’analyse s’arrête à la fermeture de la fenêtre.

Détection des pages anciennes disponible pour le site actif.

DevGitBrowser utilise Chromium normalement. Les sites qui nécessitent réellement Internet Explorer peuvent être ouverts dans une fenêtre Windows séparée avec MSHTML (moteur IE historique), à ta demande. Ce mode n’est pas conseillé pour les sites modernes, les webcams ou les informations sensibles.

Zoom des pages

Agrandir ou réduire le site actuellement ouvert, sans changer la taille des menus.

100 %

Téléchargements

Une fenêtre « Enregistrer sous » est présentée pour chaque téléchargement. Aucun fichier ne s’exécute automatiquement.

Dossier Téléchargements de Windows

Données de navigation

Effacer le cache sans déconnexion, ou vider les cookies et les données de sites. Cette seconde action déconnectera des sites et peut supprimer leur stockage local, y compris celui d’extensions.

Réseau / proxy

Un proxy n’est pas un VPN. DevGitBrowser ne promet pas l’anonymat ou la protection contre toutes les fuites réseau.
