    DÉVELOPPEMENT • INTÉGRATION

    GitHub privé

    MatchPulse est fournie avec DevGitBrowser. Tes extensions personnelles restent réservées au dépôt privé lié à ton compte.

    Non connecté à GitHub

    1. Connecter ton compte

    Crée un fine-grained personal access token sur GitHub, avec la permission Contents: Read uniquement pour ton dépôt privé. Le jeton est chiffré localement avec les services Windows, jamais intégré à l’installeur.

    2. Dépôt privé autorisé

    Le dépôt doit appartenir au compte connecté. Les extensions doivent se trouver dans extensions/nom-extension/manifest.json.

    Ajout automatiqueAprès chaque push sur GitHub, l’application vérifie le dépôt toutes les 90 secondes et ajoute les extensions compatibles. Aucun dossier local externe n’est accepté. MatchPulse est incluse automatiquement.

      🌍 VPN DevGit (gratuit)

      Le trafic du navigateur passe par le réseau chiffré Tor : ton adresse IP est masquée et tu peux choisir le pays de sortie pour accéder à des contenus bloqués dans ton pays. Gratuit, sans compte, sans limite de données. Plus lent qu’une connexion directe ; certains sites (streaming, banques) peuvent refuser les connexions via Tor. Ne protège que DevGitBrowser, pas les autres logiciels.
